## 1. Mandatory Pre-Implementation Workflow

Before implementing, styling, or refactoring any frontend code:
1. **Read `DESIGN.md`:** Review the single source of truth for design tokens, typography scale, spacing, and anti-patterns.
2. **Consult Design Skills in `.agent/skills/`:**
   - `human-quality-frontend`: Follow the 10-step design workflow (Understand -> Research -> Define -> Implement -> Humanize -> Inspect -> Critique -> Refine -> Verify -> Report).

   - `awesome-design-md`: Benchmark component structures against real-world systems.
   - `ponytail`: Apply senior dev restraint (simplest change that fully solves the problem).
   - `impeccable`: Audit typography rhythm, color contrast, and component density.
   - `humanizer`: Review and refine all visible copy to sound natural, specific, and respectful.
3. **Inspect Existing Components:** Check `src/components/ui/` and existing page components before introducing new styling or abstractions.
4. **Inspect Browser Output:** Use actual browser inspection across Desktop (1440px), Tablet (768px), and Mobile (390px/320px).
