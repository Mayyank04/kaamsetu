### 1. Ethical Lending Charter for Informal Artisans

Informal skilled workers frequently suffer predatory micro-lending traps: exorbitant daily interest rates (often 36%-120% APR), hidden loan processing deductions, and aggressive recovery agents.

KAAMSETU establishes a strict **Responsible Finance Governance Framework** for vocational tool-financing pilots:

```
+----------------------------------------------------------------------------------------------------+
|                               THE 6 PILLARS OF RESPONSIBLE FINANCE                                 |
|                                                                                                    |
|  1. RBI-Regulated Partners Only: Zero unregulated fintech lenders or private loan sharks.          |
|  2. Strict Interest Capping: Maximum APR capped at <= 14.0% per annum (simple reducing balance).   |
|  3. Wage Lien Prohibition: Loan EMIs can NEVER be automatically deducted from worker skill wages.   |
|  4. 15-Day Unconditional Cooling-Off: Worker can return equipment for full cancellation & refund.  |
|  5. Bundled Asset Insurance: All tools insured against theft, accidental breakage, and site damage. |
|  6. Zero Worker Pre-Payment Penalties: Artisans can repay early at any time with ₹0 penalty fees.  |
+----------------------------------------------------------------------------------------------------+
```

### 2. Wage Lien Prohibition: Strict Architectural Invariant

A critical vulnerability in gig-economy tool financing is the "debt-tethered worker," where platform operators deduct loan repayments directly from daily or weekly earnings before disbursing wages.

In KAAMSETU:
$$\mathbf{Platform\ Gross\ Payout = 100\%\ of\ Customer\ Booking}$$
- Under no circumstances can a lending partner place an automated lien, garnishment, or deduction on KAAMSETU's wage payout pipeline.
- Worker wage disbursements and tool loan repayments are kept strictly partitioned in completely separate banking channels.
- If an artisan experiences an illness or gap between jobs, their earned wages on KAAMSETU remain 100% protected and unencumbered.
