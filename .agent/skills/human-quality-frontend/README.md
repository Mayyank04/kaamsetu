# Human-Quality Frontend Design System

An orchestration skill for Antigravity that integrates visual taste, design-system standards, human copy, engineering restraint, and visual quality assurance into a disciplined, 10-step web design workflow.

## Integrated Capabilities
1. `design-taste-frontend` (`taste-skill` v2.5.1)
2. `awesome-design-md` (84 production design systems)
3. `humanizer` (v4.0.0)
4. `ponytail` (v1.0.0)
5. `impeccable` (v4.9.1)

## 10-Step Workflow
Understand -> Research -> Define -> Implement -> Humanize -> Inspect -> Critique -> Refine -> Verify -> Report.
