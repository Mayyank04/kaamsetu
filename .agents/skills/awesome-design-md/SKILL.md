# Awesome DESIGN.md

A design-system research and reference skill powered by 84 production design systems extracted from world-class developer, tech, and consumer websites.

## When to use

- When starting a new web project and deciding on typography, color tokens, layout grids, and component styling.
- When drafting or refining a project's `DESIGN.md`.
- When researching real-world color palettes (Linear deep dark canvas, Stripe high-contrast light mode, Apple typography scale, Wise international accessibility).

## Reference Library

This skill contains the complete `design-md/` directory with 84 production design systems:
- `design-md/linear.app/DESIGN.md`: Deep near-black (#010102) product canvas with #5e6ad2 accent.
- `design-md/stripe/DESIGN.md`: Precision light-mode financial canvas with rich semantic hierarchy.
- `design-md/apple/DESIGN.md`: Restrained editorial typography with SF Pro scale.
- `design-md/vercel/DESIGN.md`: High-contrast monochrome developer canvas with Geist font family.
- `design-md/supabase/DESIGN.md`: Emerald green accents on structured dark panels.
- `design-md/raycast/DESIGN.md`: Compact utilitarian macOS desktop-inspired layout.

## How to use in a project

1. Explore matching domains in `design-md/<domain>/DESIGN.md`.
2. Extract relevant token scales (spacing, radii, typography, elevation).
3. Author the project's own `DESIGN.md` tailored to its specific user needs. Never copy a brand identity blindly.
